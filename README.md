# Python Socket Chat

A simple client-server chat application built with Python sockets.

## Features
- Real-time two-way chat
- Basic client-server architecture 
- Works on PC, Linux, and Termux
- Demonstrates networking fundamentals

## How to Run
1.  **Start Server**: `python server.py`
2.  **Start Client**: `python client.py`
3.  **Important**: Change `SERVER_IP` in `client.py` to the server's IP address

## Tech Stack
- Python 3
- Socket Library
